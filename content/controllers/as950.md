## Programming
> Configures data logging, the alarms and the sampling program.

### Datalog Programming
> Select the measurements to record and how often they are saved to the data log.

- change_port_assignments: Change Port Assignments
  > Select the sensor(s) that will be connected to the Sensor 1 port and the Sensor 2 port.
- channel_logging: Channel Logging
  > Select a measurement source and the measurement to record to the data log.
- logging_intervals: Logging Intervals
  > Sets the primary and secondary logging intervals for each measurement. Options: 1, 2, 3, 5, 6, 10, 12, 15, 20, 30 or 60 minutes.

### Alarm Programming
> Select and configure the alarms that show on the Status screen and are recorded to the alarm log.

- system_alarms: System Alarms
  - add_new_system_alarm: Add New Alarm
    > Select a system alarm to add: Program Start, Program End, Bottle Change, Pump Forward, Pump Reverse, Sample Complete, Entire Sample, Missed Sample, Purge Error, Distributor Error, Pump Fault, Full Bottle.
- channel_alarms: Channel Alarms
  - add_new_channel_alarm: Add New Alarm
    > Select a channel alarm (setpoint alarm) for a recorded measurement. Options: Low/Low, Low, High, High/High, Rate of Change (rain only).
    - low_low: Low/Low
      > Sets the lowest alarm setpoint and the deadband for the lowest alarm setpoint.
    - low: Low
      > Sets the low alarm setpoint and the deadband for the low alarm setpoint.
    - high: High
      > Sets the high alarm setpoint and the deadband for the high alarm setpoint.
    - high_high: High/High
      > Sets the highest alarm setpoint and the deadband for the highest alarm setpoint.
    - rate_of_change: Rate of Change
      > Sets the alarm setpoint, deadband and the amount of time for the rate of change (rain only).
    - alarm_action: Alarm Action
      - log_only: Log Only
        > Sets the alarm to be recorded to the alarm log when the alarm occurs.
      - switch_log_interval: Switch Log Interval
        > Sets the data logging interval to change to the secondary logging interval while the alarm is active.

### Sample Programming
> Configure the sampling program: pacing, volume, distribution, start and stop conditions.

- program_type: Program Type
  > Select the type of sampling program. Options: Custom Single, Custom Dual, CTVV, Stormwater, Setpoint Sampling.
- total_bottles: Total Bottles
  > Selects the number of bottles in the sampler.
- bottles_per_program: Bottles per Program
  > Selects the number of bottles used by each sampling program (Custom Dual and Stormwater only).
- bottle_volume: Bottle Volume
  > Enters the volume capacity of each bottle.
- tubing: Tubing
  - tubing_length: Length
    > Enters the length of the intake tubing from the strainer to the liquid detector.
  - tubing_diameter: Diameter
    > Selects the diameter of the intake tubing: 6.33 mm (¼ in.) or 9.5 mm (3/8 in.).
- pacing: Pacing
  > Select when a sample is collected.
  - time_weighted: Time Weighted
    > Collects a sample at a set time interval. Sets the time interval between samples (1 minute to 999 hours) and whether the first sample is taken immediately or after the first interval.
  - flow_weighted: Flow Weighted
    > Collects a sample at a set flow interval. Requires an external flow meter or optional flow sensor. Configures flow source, override, target volume and take-first setting.
  - time_table: Time Table
    > Collects a sample at two or more configurable time intervals. Sets number of intervals and configures each interval.
  - flow_table: Flow Table
    > Collects a sample at two or more configurable flow intervals. Sets number of intervals and configures each interval. Requires an external flow meter or optional flow sensor.
  - event: Event
    > Collects a sample when one or more selected channel alarms occur. Sets event type, selects channel alarms and event trigger (any or all alarms).
- sample_volume: Sample Volume
  > Select the volume of each sample.
  - fixed: Fixed
    > Sets the sample volume to a fixed quantity (10 to 10,000 mL).
  - variable: Variable
    > Sets the sample volume to increase linearly as the flow rate increases or decreases between a configured low and high flow rate. Requires the liquid detector to be enabled.
- distribution: Distribution
  > Select the sample distribution among the bottles.
  - sample_based: Sample Based
    > Divides each sample between a selected number of bottles or puts multiple samples in one bottle. Sets Bottles per Sample (BPS) and Samples per Bottle (SPB).
  - time_based: Time Based
    > Puts samples collected during a time interval into each bottle. Sets Duration (5 minutes to 24 hours) and First Bottle.
- program_start: Program Start
  > Select when the sampling program starts after RUN/HALT is pushed.
  - immediately_on_run: Immediately on Run
    > The sampling program starts immediately when RUN/HALT is pushed.
  - on_trigger: On Trigger
    > The sampling program starts (or starts and stops) when a trigger occurs.
    - setpoint_trigger: Setpoint
      > Starts the program when selected channel alarms occur. Configures setpoint selection, start trigger (any/all), delay and control (Start Only or Start & Stop).
    - external_aux_trigger: External AUX
      > Starts the program when the external flow meter or third-party device connected to the AUX I/O port sends a signal. Configures delay and control (Start Only or Start & Stop).
  - after_delay: After Delay
    > The sampling program starts after the selected delay. Delay types: None, Date and Time, Time Duration, Flow Duration, Slave Sequential, Slave Parallel.
  - on_schedule: On Schedule
    > The sampling program starts on selected day(s) of the week and time(s). Configures up to 12 schedule intervals and an optional one-time delay.
- program_end: Program End
  > Select when the sampling program stops.
  - none: None
    > The sampling program operates continuously.
  - after_samples: After Samples
    > The sampling program stops after a set number of samples are collected.
  - date_and_time: Date and Time
    > The sampling program stops at a set date and time.
  - time_duration: Time Duration
    > The sampling program stops after a number of hours (1 to 999 hours).

## Review Data
> Shows the sampling history and the measurement data (data log).

### Sample History
> Shows each sample collected, the time collected and whether collection was completed or not.

- all_samples: All Samples
  > Shows the sample collection time, sample number, bottle number(s) and sample volume for each sample.
- missed_samples: Missed Samples
  > Shows the sample collection time, sample number and the reason each sample was not collected.

### Measurement Data
> Shows the measurements recorded to the data log in table or graph format.

- view_type: View Type
  > Changes the view between table format and graph format.
- zoom: Zoom
  > Changes the graph view to one week, one day or one hour of measurements (graph view only).
- jump_to_newest: Jump to Newest
  > Shows the last measurement recorded.
- jump_to_oldest: Jump to Oldest
  > Shows the first measurement recorded.
- jump_to_date_time: Jump to Date & Time
  > Shows the measurement recorded at the entered date and time.

## Manual Operation
> Collects a grab sample, moves the distributor arm or operates the pump manually.

### Grab Sample
> Collects a grab sample to verify sample volume or bypass the sampling program.

- grab_sample_volume: Sample Volume
  > Enter the volume to collect. If the liquid detector is enabled, enter the volume to be verified; if disabled, enter the volume specified in the sampling program.

### Move Distributor Arm
> Moves the distributor arm to a selected bottle position.

- bottle_number: Bottle Number
  > Enter the number of the bottle to move the distributor arm over.

### Operate Pump
> Operates the pump in the forward or reverse direction.

- pump_forward: Pump (Run Forward)
  > The pump operates in the forward direction to collect a sample.
- purge_backward: Purge (Run Backward)
  > The pump operates in the reverse direction to purge the intake tubing.

## Calibration
> Calibrates the sample volume, attached sensors and the analog input at the AUX port.

### Volume
> Calibrate or adjust the sample volume.

- sample_volume_cal: Sample Volume
  > Calibrates the sample volume. With liquid detector enabled, collects a sample and adjusts based on actual volume collected. With liquid detector disabled, calibrates by time.
- user_adjust: User Adjust
  > Adjusts the sample volume calibration by entering a percentage adjustment value.

### Sensor Calibration
> Calibrate the sensors connected to the sampler.

### Cabinet Temp Cal
> Calibrate the cabinet temperature (AWRS sampler only).
> Refer to the service manual on the manufacturer's website for the calibration procedure.

## Hardware Setup
> Configures the sampler, sampler ports and attached sensors. Configures and calibrates the liquid detector.

### Sampler
> Configure general sampler settings.

- site_id: Site ID
  > Enters the name for the sampling location (16 characters).
- rinses: Rinses
  > Sets the number of intake tube rinses before a sample is collected (0 to 3).
- sample_retries: Sample Retries
  > Sets the number of sampling tries after a sampling failure occurs (0 to 3).

### Configure Sensors
> Configures the attached sensors.

- slot: Device {{slot_index}}

#### Sensor Options
> Common options available for each sensor.

- setup_wizard: Setup Wizard
  > Configures all the sensor settings and calibrates the sensor following screen prompts.
- calibration_sensor: Calibration
  > Calibrates the sensor.
- basic_settings: Basic Settings
  > Configures the basic sensor settings.
- flow_settings: Flow Settings
  > Configures the sensor settings used to calculate flow.
- application_settings: Application Settings
  > Configures sensor settings that control sensor operation (US900x only).
- advanced_settings: Advanced Settings
  > Configures optional, advanced sensor settings.
- restore_defaults: Restore Defaults
  > Sets the sensor settings and calibration back to factory defaults.

### AUX and I/O Port
> Configures the AUX I/O port for connection to a Hach flow meter or third-party device.

- type: Type
  > Sets the port type: AUX or RS485 (configured via Rain and RS485 Port).
- mode: Mode
  > Sets the AUX I/O port mode. Options: Sample Event (sends sample info to a flow meter when a sample is collected), Program Complete (sends a signal when the sampling program is complete).
- flow_reading: Flow Reading
  > Selects the type of flow input signal from the flow meter. Options: AUX-Pulse or AUX-mA (4–20 mA).
- flow_unit: Flow Unit
  > Selects the flow units shown on the display (AUX-mA mode). Options: m³ or L per day, hour, minute or second.
- ma_4_value: 4mA Value
  > Enters the flow volume that corresponds to a 4 mA input at the AUX I/O port.
- ma_20_value: 20mA Value
  > Enters the flow volume that corresponds to a 20 mA input at the AUX I/O port.
- calibrate_aux: Calibrate
  > Calibrates the analog input by supplying 4 mA and 20 mA to the AUX I/O port.
- restore_defaults_aux: Restore Defaults
  > Sets the AUX I/O port settings and analog input calibration to factory defaults.

### Liquid Detect
> Enables, disables and calibrates the liquid detector.

- status: Status
  > Enables or disables the liquid detector. Enabled (default): uses the liquid detector to sense liquid in the tube for volume accuracy. Disabled: for pressurized lines or when the sampler is below the sample source.
- calibrate_liquid: Calibrate
  > Calibrates the liquid detector (only with guidance of technical support).

### Rain and RS485 Port
> Configures the Rain port for a Hach tipping bucket rain gauge or RS485 communications.

- port_mode: Port Mode
  > Options: Rain or RS485.
- modbus_address: Modbus Address
  > Sets the Modbus address when RS485 is selected (1 to 255).
- baud_rate: Baud Rate
  > Sets the baud rate when RS485 is selected. Options: 9600, 19200, 38400, 57600 or 115200.
- parity: Parity
  > Sets the parity when RS485 is selected. Options: None, Even or Odd.

### Thermal
> Sets and calibrates the temperature inside the AWRS refrigerated cabinet (AWRS sampler only).

- cabinet_temp_set: Cabinet Temperature
  > Sets the temperature inside the AWRS refrigerated cabinet. Options: 2.00 to 10.00 °C (default: 4.00 °C).

## Diagnostics
> Shows status, logs and memory use. Runs diagnostic tests on components.

### Status diag
> Shows the Status screen including sample status, data log status, alarm status and hardware status.

### Event log
> Shows the event log. Displays total events and occurrences per event type.

### Alarm log
> Shows the alarm log. Displays total alarms and occurrences per alarm type.

### Sensor ports
> Triggers the connected sensors to do a measurement and shows advanced diagnostic information, sensor type and firmware version.

### Aux IO diag
> Shows the configuration settings for the AUX I/O port, the flow input signal and the flow value.

### Distributor
> Moves the distributor arm to all bottle positions to test distributor arm operation.

### Keypad
> Shows each key that is pushed on the keypad for keypad testing.

### Display
> Sets each pixel of the display to on and off in different patterns for display testing.

### Memory
> Shows the percent of controller memory used.

### Pump
> Shows total run time, forward run time and reverse run time of the pump motor.

- reset_counters: Reset Counters
  > Resets the pump cycle count to 0 after the pump tubing is changed.

## General settings
> Shows instrument information. Configures display, security, units, tubing life. Erases data.

### About
> Shows system information: model name, model type, serial number, boot firmware version, firmware version and firmware build date.

### Date and time
> Sets the time and date and selects the format. Options: dd/mm/yyyy 12h, dd/mm/yyyy 24h, mm/dd/yyyy 12h, mm/dd/yyyy 24h, yyyy/mm/dd 12h, yyyy/mm/dd 24h.

### Display settings
> Adjusts the brightness of the display (default: 50%).

### Security
> Enables security for password protection. When enabled, user settings that can change log data or the sampling program require a password. Password must be re-entered when the display switches off or the controller power is set to off.

### Language
> Sets the display language.

### Unit Preferences
> Sets the system of measurement (US Customary or Metric) and individual measurement units shown on the display.
- unit_system: Unit System
  > Sets the system of measurement that show on the display
  - unit_system_us: US Customary
  - unit_system_metric: Metric
- select_units: Select Units
  > Selects individual measurement units for the following options: level, velocity, flow, temperature, surface velocity, distance, minimum distance, maximum distance, surge level, rain, cabinet temperature, level raw and surge velocity.

### Tubing Life
> Sets a reminder when the pump tubing is to be changed. Enter the number of pump cycles for the reminder (10 to 99,999). An event is recorded to the event log when total pump cycles exceed the set value.

### Clear Data
> Erases the sample history and/or selected logs.
  - clear_sample_history: Sample History
  - clear_data_log: Data Log
  - clear_event_log: Event Log
  - clear_alarm_log: Alarm Log
  - clear_diag_log: Diagnostics Log

### Restore Factory Defaults
> Sets all controller settings back to factory defaults and erases logs and sample history. The display shows the startup screen for approximately 2 minutes during the restore process.

## Export/Import
> Saves measurement data, sample history and program settings to a USB flash drive. Copies program settings from a USB flash drive to the sampler.

### Export data
> Saves a copy of user settings, log files, sample history and manufacturer settings to the USB flash drive in FSDATA Desktop format.

### Export settings
> Saves a copy of the user settings to the USB flash drive. Select a filename (Settings 1 to 10).

### Import settings
> Shows the configuration files saved to the USB flash drive and copies the selected file to the controller. Replaces all user settings and erases log data.

### USB drive info
> Shows the total, used and free memory on the USB flash drive.
