### Network Setup
> Only appears if a network or analog output module is installed.
- network_profibus: PROFIBUS SETUP
  - telegram: Telegram
    > Manages the Telegram data structure.
    - view_configuration: View configuration
      > Views the current Telegram data configuration.
    - start_auto_config: Start Auto config
      > Starts a new auto configuration process which may need some sensor setup changes.
    - add_remove_devices: Add/Remove devices
      > Selects the devices included in the Telegram.
    - add_remove_tags: Add/remove tags
      > Selects telegram data tags for each device.
    - setup_telegram_mode: Setup telegram mode
      > Selects the auto configuration (default) or the manual configuration mode.
  - profibus_dp: Profibus DP
    - address: Address
      > Changes the slave address.
    - data_order: Data order
      > Sets the sequence of bytes when transmitting floating point values.
      - data_order_normal: Normal
        > IEEE Float Big Endian (Default setting) - The pairs are not swapped. This mode fits to all known Profibus master systems.
      - data_order_swapped: Swapped
        > IEEE Float word wise swapped: Swaps the first pair of bytes with the last pair.
  - simulation: Simulation
    > Simulates two floating point values and error/status to substitute a real instrument.
    - simulation_enable: Simulation
      > Turns the simulation on or off.
    - period: Period
      > Sets the time the first floating point value needs to run through the whole range between MINIMUM and MAXIMUM.
    - maximum: Maximum
      > Sets the upper limit for the first floating point value.
    - minimum: Minimum
      > Sets the lower limit for the first floating point value.
    - error: Error
      > The value entered in this menu will be set in the first simulated tag.
    - status: Status
      > The value entered in this menu will be set in the second simulated tag.
    - toggle: Toggle
      > Changes the direction of the simulated ramp.
    - test_maint: Test/maint
      - test_maint_enabled: Enabled
        > Sets the TEST/MAINT bit (0x0004) of every status register of all slaves to indicate "Service" mode.
      - test_maint_disabled: Disabled
        > Normal operation mode (Default setting)
  - version: Version
    > Software version of the Profibus network card.
  - location: Location
    > Edits the location name.
  - status_network: Status
    > Indicates the Profibus network card status. Please wait (shown until all slaves have been found); PLC configure err (shown when a wrong configuration is received from the PLC); Ready (shown when ready to send data to Profibus); Online (shown when connected to PLC and data is sent).
