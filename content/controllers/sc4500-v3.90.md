## Controller

### General
> Configure the controller language, time, date, facility, location and display options.

- language: Language
  > Sets the language shown on the controller display and in the log files.
- time_zone: Time zone
  > Sets the time zone by region and city.
- time_format: Time format
  > Sets the time format: 12 h (default) or 24 h.
- time: Time
  > Sets the time.
- date: Date
  > Sets the date.
- facility: Facility
  > Sets the name of the facility (32 characters maximum).
- location: Location
  > Sets the name of the location (32 characters maximum).
- device_menu: Device menu
  > Shows the controller name and serial number; allows changing the Name setting.
- display: Display
  > Sets display options including brightness, screen lock, and waiting time (inactivity period).

### Password
> Set password protection to prevent unwanted changes to specific controller settings and device menus.

- password_protection: Password protection
  > Enables or disables password protection for protected menus.
- change_password: Change password
  > Changes the controller password (4–8 characters, case sensitive, alphanumeric and special characters).

### Connectivity
> Configure network connectivity options for the controller.

#### LAN
> Configure LAN Ethernet port settings.

- ethernet_ports: Ethernet ports
  > Sets the Ethernet port configuration: None, Chaining, Split, Mix IEP, or IEP only.
- lan_port_config: LAN port configuration
  > Configures IP address settings (DHCP on/off, IP address, Netmask, Default gateway, DNS address) for LAN ports.

#### Wi-Fi
> Configure WiFi network connection via external USB box WiFi adapter.

- wifi_connectivity: Wi-Fi connectivity
  > Enables or disables Wi-Fi connectivity and selects the access point.
- network: Network
  > Selects the WiFi access point and enters credentials (WEP, WPA2 Personal/PSK, or WPA2 Enterprise).

#### Cellular
> Configure cellular network connection via external USB box cellular (for Claros connection only).

- cellular_connectivity: Cellular connectivity
  > Enables or disables cellular connectivity.
- provider: Provider
  > Sets the provider name (Access Point Name). Options: Telenor (NA/Verizon) or Other.
- apn: APN
  > Shows or sets the provider/access point name.
- sim_pin: SIM PIN
  > Sets the SIM card PIN.
- user_name: User name
  > Sets the cellular network user name.
- password: Password
  > Sets the cellular network user password.
- internet_sharing: Internet sharing
  > When set to on, shares the internet connection with other controllers.

#### Claros
> Configure connection to Claros cloud platform.

- claros: Claros
  > Enables or disables the Claros connection.

#### HCNB
> Configure the Hach Controller Network Bus for sharing PLC connections across multiple controllers.

- hcnb: HCNB
  > Enables or disables the Hach Controller Network Bus (HCNB).

### USB transfer
> Manage data downloads and firmware/software updates via USB flash drive.

#### Controller update
> Installs controller firmware updates from a USB flash drive.

#### Sensor update
> Installs sensor firmware updates from a USB flash drive.

#### Software module
> Manages installation and deletion of software modules (e.g., RTC module).

- installation: Installation
  > Installs a software module from the USB flash drive.
- deletion: Deletion
  > Deletes an installed software module from the controller.

#### Logs
> Downloads data and event logs (.csv files) for all connected devices to the USB flash drive.

#### Service logs
> Downloads diagnostic data to the USB flash drive.

### License
> Enter or view license keys to activate controller software upgrades and software modules.

- enter_license_keys: Enter license keys
  > Enters a license key to upgrade the controller with new functions.
- activated_license_keys: Activated license keys
  > Shows a list of all activated software on the controller.

### Service
> Service and recovery options for the controller.

- restore_firmware: Restore firmware
  > Reverts the controller to the software version installed before the most recent firmware update.
- restart_controller: Restart controller
  > Restarts the controller.
- reset_password: Reset password
  > Resets the controller password back to the default ("SC4500").
- hach_service: Hach service
  > Access for Hach service personnel.

## Outputs
> Configure analog and digital outputs, relays, and communication protocols.

### Modbus TCP
> Configure Modbus TCP/IP communication for data transmission to measurement and control systems.

- modbus_tcp: Modbus TCP
  > Enables or disables Modbus TCP.
- ip_address: IP address
  > Shows the IP address used for Modbus TCP.
- tcp_port: TCP Port
  > Shows the TCP port used for Modbus TCP.
- telegram_modbus_tcp: Telegram
  > Manages the Telegram data structure for Modbus TCP; selects devices and data tags.
- modbus_address: Modbus address
  > Sets the address (1–255) of the Modbus secondary device configured in the Telegram menu.
- virtual_modbus_slave: Virtual modbus slave
  > Adds virtual secondary devices as copies of devices configured in the Telegram menu.
- data_order: Data order
  > Sets the byte sequence for transmission of floating point values: Normal (default) or Swapped.
- simulation: Simulation
  > Simulates two floating point values and errors/statuses to replace an instrument.
- status: Status
  > Shows information about the data transfer status.

### Profibus DP
> Configure Profibus DP communication for factory automation.

- profibus_dp: Profibus DP
  > Enables or disables Profibus DP and sets fieldbus address and data order.
- telegram_profibus: Telegram
  > Manages the Telegram data structure for Profibus DP; selects devices and data tags.
- simulation_profibus: Simulation
  > Simulates two floating point values and errors/statuses to replace an instrument.
- version: Version
  > Shows the software version of the Profibus network module.
- location_profibus: Location
  > Sets the location name to identify the Profibus network module.
- status_profibus: Status
  > Shows the condition of the Profibus network module and PLC configuration errors.
- input_from_plc: Input from PLC
  > Sets data log interval and configures text parameter units received from the PLC.
- reset_configuration: Reset configuration
  > Resets the Profibus DP configuration back to factory settings.

### High voltage relay
> Configure and test the two high-voltage non-powered relays.

#### System setup
> Configure trigger conditions and parameters for each high-voltage relay.

- source_hvr: Source
  > Sets the source device for the relay output.
- parameter_hvr: Parameter
  > Sets the parameter for the relay output based on the selected source.
- data_view_hvr: Data view
  > Sets the value displayed and stored in the data logger: Input configuration (default) or Relay contact status.
- function_hvr: Function
  > Sets the relay function: Alarm, Feeder control, 2 point control, Warning, Pulse width control, Frequency control, Timer, or System error.
- transfer_hvr: Transfer
  > Sets the transfer value: Relay is energized or Relay is de-energized (default).
- input_value_hvr: Input value
  > Shows the process value read from the selected source.
- data_logger_interval_hvr: Data logger interval
  > Sets the interval at which the shown value is saved to the data logger.

#### Test/Maintenance
> Test the internal high-voltage relays.

- function_test_hvr: Function test
  > Tests the selected relay by setting Relay 1, Relay 2, or All to ON or OFF.
- relay_status_hvr: Relay status
  > Shows the current condition of the relays.

### mA outputs
> Configure the optional 4–20 mA analog output module (five outputs).

#### System setup
> Configure each analog output channel.

- source_ma: Source
  > Selects the analog output to configure and sets the parameter from the selected device.
- parameter_ma: Parameter
  > Changes the parameter selected on the source option.
- data_view_ma: Data view
  > Sets the measured value shown on the display and saved to the data log: Input value (default) or Current.
- function_ma: Function
  > Sets the output function: Linear control or PID control.
- transfer_ma: Transfer
  > Sets the transfer value shown on the analog output when the source reports an error or is disconnected. Default: 10 mA.
- current_ma: Current
  > Shows the calculated output current in mA.
- data_logger_interval_ma: Data logger interval
  > Sets the interval at which the shown value is saved to the data logger.

#### Test/Maintenance
> Test the analog output module.

- function_test_ma: Function test
  > Tests the outputs on the selected module.
- output_status_ma: Output status
  > Shows the condition of the outputs on the selected module.

### Modbus RS232/RS485
> Configure the optional Modbus RS232/RS485 communication module.

- name_modbus_rs: Name
  > Changes the name of the Modbus module (maximum 16 characters).
- modbus_address_rs: Modbus address
  > Sets the Modbus device address.
- baud_rate: Baud rate
  > Sets the data transmission rate in bits per second. Options: 9600, 19200 (default), 38.4K, 57.6K, or 115.2K.
- modbus_mode: Modbus mode
  > Sets the Modbus mode: RTU (default) or ASCII.
- data_order_rs: Data order
  > Sets byte order for floating point transmission: Little endian (default) or Big endian.
- parity: Parity
  > Sets per-byte error checking for RS232/RS485: None (default), Even, or Odd.
- stop_bits: Stop bits
  > Sets the number of stop bits: 1 (default) or 2.

#### Diagnostics/Test
> Diagnostics and test options for the Modbus RS232/RS485 module.

- network_timing: Network timing
  > Sets maximum response time values: Read timeout, Register write timeout, File write timeout, and File preparation timeout.
- modbus_statistics: Modbus statistics
  > Shows the number of successful and failed Modbus requests.
- clear_statistics: Clear statistics
  > Deletes the counted messages.
- module_information: Module information
  > Shows the software version, bootloader version and serial number of the Modbus module.
- reset_modbus: Reset
  > Resets the Modbus settings to factory defaults.
