  > Select from list of connected devices
  - error_list: ERROR LIST

  - warning_list: WARNING LIST
    > Displays a list of warnings currently present in the probe.
  - reminder_list: REMINDER LIST
    > Displays a list of reminders currently present in the probe.

    > Displays a list of warnings currently present in the probe.

## SC1000 SETUP
> The SC1000 SETUP menu contains the main configuration settings for the SC1000 Controller.
- output_setup: OUTPUT SETUP
  - ma_output_int_ext: MA OUTPUT INT/EXT
    - select_output_card: Select OUTPUT card 1,2,3 or 4
      - select_source: SELECT SOURCE
        > Selects a probe or creates a formula which delivers the process value that is processed by the current output card.
      - set_parameter: SET PARAMETER
        > Selects a parameter of the selected source.
      - data_view: DATA VIEW
        > Sets the displayed and logged measured value.
        - input_value: INPUT VALUE
          > Displays the process value which is read from the selected source after it has been processed by the internal formula parser (if prompted)
        - current: CURRENT
          > Displays the calculated output current
      - set_function: SET FUNCTION
        - linear_control: LINEAR CONTROL
          > Tracks the measurement value.
        - pid_control: PID CONTROL
          > Sets the SC1000 Controller as a PID controller.
      - set_transfer: SET TRANSFER
        > Sets the substitute value for the output current in case the selected source reports an internal error, is disconnected from the system or its output mode is set to 'Transfer value'.
      - on_error_mode: ON ERROR MODE
        - hold: HOLD
          > The current output card operates constantly with the last valid value read from the selected source.
        - set_transfer_error: SET TRANSFER
          > The current output card uses a substitute value for the output current.
      - set_mode: SET MODE
        - direct: DIRECT
          > The SNAP SHOT value is lower than the SETPOINT and vice versa.
        - reverse: REVERSE
          > The SNAP SHOT value is higher than the SETPOINT and vice versa.
      - set_filter: SET FILTER
        > Sets the record time (in seconds)
      - scale_0_ma_4_ma: SCALE 0 mA/4 mA
        > Sets the output current range to 0-20 mA or 4-20 mA.
      - set_high_value: SET HIGH VALUE
        > Sets the selected source value when the output current shall be 20 mA.
      - set_low_value: SET LOW VALUE
        > Sets the selected source value when the output current shall be 0 mA (Scale is 0-20 mA) respectively 4 mA (Scale is 4-20 mA).
      - maximum: MAXIMUM
        > Sets an upper limit for the possible output current value.
      - minimum: MINIMUM
        > Sets the lower limit for the output current.
      - set_setpoint: SET SETPOINT
        > Sets the process value
      - proportional: PROPORTIONAL
- current_inputs: CURRENT INPUTS
- relay: RELAY
- wtos: WTOS
