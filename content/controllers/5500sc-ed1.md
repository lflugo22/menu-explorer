## Main Menu

- start_stop_analyzer: START ANALYZER / STOP ANALYZER
  > Starts the analyzer or puts it into shutdown mode; toggles based on current state.

### REAGENTS/STANDARDS
> Sets and resets reagent, standard and cleaning solution levels; primes reagents; sets the blank value if applicable.
- set_reagent_level: SET REAGENT LEVEL
  > Sets the volume of a specific reagent in the reagent bottle to an approximate value; range 1–100%.
- set_standard_level: SET STANDARD LEVEL
  > Sets the volume of a specific standard solution in the standard bottle to an approximate value; range 1–100%.
- set_cleaning_level: SET CLEANING LEVEL
  > Sets the volume of the cleaning solution in the cleaning solution bottle to an approximate value; range 1–100%.
- reset_reagent_levels: RESET REAGENT LEVELS
  > Sets the volume of reagent in all reagent bottles to 100% full.
- reset_standard_levels: RESET STANDARD LEVELS
  > Sets the volume of standard solution in the standard bottle to 100% full.
- reset_cleaning_solution_levels: RESET CLEANING SOLUTION LEVELS
  > Sets the volume of the cleaning solution in the cleaning solution bottle to 100% full.
- prime_reagents: PRIME REAGENTS
  > Starts the flow of all reagents through the tube and valve system to remove bubbles after reagent change.
- enter_blank_value: ENTER BLANK VALUE
  > Applicable only to silica analyzers with Hach-prepared reagents: sets the reagent blank value to the value printed on the R1 bottle label.

### GRAB SAMPLE
> Measures an external sample or dispenses a sample for external analysis.
- grab_sample_in: GRAB SAMPLE IN
  > Analyzes an external sample or standard.
- grab_sample_out: GRAB SAMPLE OUT
  > Removes a sample directly from a sample line for external analysis.

### SETUP SYSTEM
> Sets the main configuration settings for the analyzer.
- meas_mode: MEAS MODE
  > Changes the mode of the measurement cycle; options: interval or continuous (default, ~every 9 minutes).
- edit_interval: EDIT INTERVAL
  > Changes the interval time when MEAS MODE is set to interval; options: 10 to 240 minutes (default 15 minutes).
- meas_units: MEAS UNITS
  > Changes the measurement units shown on the display and in the data log; options: ppb (default), ppm, mg/L, µg/L.
- signal_average: SIGNAL AVERAGE
  > Selects the number of measurements (1–5) used to calculate an average measurement to reduce variability (default = 1).
- edit_analyzer_name: EDIT ANALYZER NAME
  > Changes the name shown on the top of the measurement screen; maximum 16 characters.
- edit_channel_name: EDIT CHANNEL NAME
  > Changes the name of the sample source shown on the measurement screen; maximum 10 characters.
- configure_sequencer: CONFIGURE SEQUENCER
  > Starts or stops measurements for individual sample sources and sets the measurement order when more than one source is present.
- sample_missing: SAMPLE MISSING
  > Sets the operation when no sample is detected; options: ON DELAY (default) or OFF DELAY.
- set_date_time: SET DATE & TIME
  > Sets the analyzer time and date.
- display_setup: DISPLAY SETUP
  > Changes the analyzer language, adjusts the order of measurements on the screen and adjusts display contrast.
- disable_reminders: DISABLE REMINDERS
  > Stops scheduled maintenance alerts for individual components (tubing, stir bar, colorimeter cell, air filter, stir motor, air relief valve, pinch valve, air compressor, reagent valves, sample valves, standard valves, colorimeter LED, fan filter, air check valve).
- manage_devices: MANAGE DEVICES
  > Installs or removes input modules.
- instrument_information: INSTRUMENT INFORMATION
  > Shows the analyzer information.
- calculation: CALCULATION
  > Sets up variables, parameters, units and formulas for the analyzer.
- setup_outputs: SETUP OUTPUTS
  > Selects and configures the 4–20 mA setup, the relay setup and the error hold mode.
  - ma_setup: 4-20 mA Setup
    - ma_activation: ACTIVATION
      > Sets the output parameters such as high and low values; available options change with the selected function.
    - ma_select_source: SELECT SOURCE
      > Selects the output; options: None, the analyzer name, or a configured calculation.
    - ma_set_parameter: SET PARAMETER
      > Selects the measurement channel from the list.
    - ma_set_function: SET FUNCTION
      > Selects a function: LINEAR CONTROL, PID CONTROL, LOGARITHMIC, or BILINEAR.
    - ma_set_transfer: SET TRANSFER
      > Sets the transfer value when TRANSFER is selected as the ERROR HOLD MODE; range: 3.0 to 23.0 mA (default 4.000).
    - ma_set_filter: SET FILTER
      > Enters a time-average filter value of 0 to 120 seconds (default = 0).
    - ma_scale: SCALE 0mA/4mA
      > Selects the scale: 0–20 mA or 4–20 mA.
  - relay_setup: Relay Setup
    - relay_activation: ACTIVATION
      > Sets the output parameters such as high and low alarm values; available options change with the selected function.
    - relay_select_source: SELECT SOURCE
      > Selects the output; options: None, the analyzer name, or a configured calculation.
    - relay_set_function: SET FUNCTION
      > Selects a function: ALARM, FEEDER CONTROL, EVENT CONTROL, SCHEDULER, WARNING, or PROCESS EVENT.
    - relay_set_transfer: SET TRANSFER
      > Selects active or inactive.
    - relay_fail_safe: FAIL SAFE
      > Selects yes or no.
- setup_network: SETUP NETWORK
  > Shows only if a network card is installed; supports Modbus, Profibus and HART communication protocols.
- security_setup: SECURITY SETUP
  > Enables or disables the pass code (default = HACH55).
- air_purge: AIR PURGE
  > Enables the air purge for use with an external air supply; options: on or off (default).
- reset_defaults: RESET DEFAULTS
  > Sets the configuration to the factory defaults.


### VIEW DATA
> Shows measurement data, analyzer data and data logs.
- log_data: LOG DATA
  > Selects the data log and/or event log with configurable start time, number of hours and/or number of readings.

#### ANALYZER DATA
> Shows the analyzer status information.

- cell_temp: CELL TEMP
  > Shows the temperature of the colorimeter cell block heater (ideally 49.8 °C to 50.2 °C).
- reagent_temp: REAGENT TEMP
  > Shows the reagent temperature before it enters the colorimeter.
- ambient_temp: AMBIENT TEMP
  > Shows the air temperature inside the electronics area.
- sample_temp: SAMPLE TEMP
  > Shows the sample pre-heater block temperature (typically 45 °C to 55 °C, could reach 58 °C).
- air_press: AIR PRESS
  > Shows the reagent air pressure in the reagent bottles (ideally 3.95 to 4.10 psi).
- led_duty_cycle: LED DUTY CYCLE
  > Depends on condition of colorimeter cell and age of analyzer (typically 7,200 to 40,000 counts).
- heater_duty_cycle: HEATER DUTY CYCLE
  > Shows the percentage of time the colorimeter heater is on to maintain a constant temperature of 50 °C.
- sample_flow: SAMPLE FLOW
  > Shows the approximate sample flow into the colorimeter, measured during the flush cycle.
- sample_press_1: SAMPLE PRESS 1
  > Shows the sample pressure before the pre-heater block (ideally 2 to 4.5 psi).
- sample_press_2: SAMPLE PRESS 2
  > Shows the sample pressure after the sample pre-heater, used to calculate sample flow.
- reagent_1_level: REAGENT 1
  > Shows the level of reagent in the reagent 1 bottle.
- reagent_2_level: REAGENT 2
  > Shows the level of reagent in the reagent 2 bottle.
- reagent_3_level: REAGENT 3
  > Shows the level of reagent in the reagent 3 bottle.
- reagent_4_level: REAGENT 4
  > Shows the level of reagent in the reagent 4 bottle (if applicable).
- std_solution_level: STD SOLUTION
  > Shows the level of the standard solution in the standard solution bottle (if applicable).
- standard_1_level: STANDARD 1
  > Shows the level of the standard solution in the standard solution 1 bottle (if applicable).
- standard_2_level: STANDARD 2
  > Shows the level of the standard solution in the standard solution 2 bottle (if applicable).
- fan_speed: FAN SPEED
  > Shows the speed of the ventilation fan.
- leak_counts: LEAK COUNTS
  > Shows the leak counts (range 0 to 1023); a count of more than 511 indicates a fluid leak.

#### MEASUREMENT DATA
> Shows the measurement information.

- last_meas_channel: LAST MEAS CHANNEL
  > Shows the last channel that was measured.
- last_meas_time: LAST MEAS TIME
  > Shows the time of the last measurement.
- last_abs: LAST ABS
  > Shows the last absorbance reading.
- last_conc: LAST CONC
  > Shows the concentration of the last measurement.
- next_meas_time: NEXT MEAS TIME
  > Shows the time of the next measurement.
- dark: DARK
  > Shows the number of A/D counts measured when the LED was off.
- ref: REF
  > Shows the reference A/D count used to compensate for natural color and turbidity.
- sample_counts: SAMPLE
  > Shows the A/D counts measurement after color development, used to determine sample concentration.
- dark_std_dev: DARK STD DEV
  > Shows the standard deviation of the dark counts from six readings.
- ref_std_dev: REF STD DEV
  > Shows the standard deviation of the reference counts from six readings.
- sample_std_dev: SAMPLE STD DEV
  > Shows the standard deviation of the sample counts from six readings.
- sample_volume: SAMPLE VOLUME
  > Shows the total sample flush volume through the colorimeter for the measurement cycle.
- meas_reagent_1: REAGENT 1
  > Shows the calculated reagent 1 delivery time to the sample based on temperature, pressure and viscosity.
- meas_reagent_2: REAGENT 2
  > Shows the calculated reagent 2 delivery time to the sample based on temperature, pressure and viscosity.
- meas_reagent_3: REAGENT 3
  > Shows the calculated reagent 3 delivery time to the sample based on temperature, pressure and viscosity.

### LINK2SC
> Lets the user share data between analyzers, process probes and compatible laboratory instruments.

- create_new_job: CREATE A NEW JOB
  > Starts the grab sample operation for the measurement value exchange between the analyzer and the laboratory.
- job_list: JOB LIST
  > Selects the job file to send to the laboratory (JOB TO LAB) or delete (ERASE JOB).
- job_id_min: JOB ID MIN
  > Specifies the minimum value for the ID number range.
- job_id_max: JOB ID MAX
  > Specifies the maximum value for the ID number range.

### SD CARD SETUP
> Shows when an SD card is installed; updates firmware and software; downloads event and data logs.

- upgrade_software: UPGRADE SOFTWARE
  > Shows when an upgrade file is available on the SD card; select the specific device for the upgrade.
- save_logs: SAVE LOGS
  > Selects the device for download and saves logs for last day, last week, last month or all.
- manage_configuration: MANAGE CONFIGURATION
  > Saves and restores backup settings, restore settings and/or transfers settings between instruments.
- work_with_devices: WORK WITH DEVICES
  > READ DEVICE FILES: selects data for each device to save on SD card (sensor diag, measurement data, cal history, cal data, test script). WRITE DEVICE FILES: shows when an upgrade file is available for a new measurement cycle script.

## Cal Menu

- start_manual_cal: START MANUAL CAL
  > Starts a calibration immediately or at the end of the current measurement cycle.
- set_auto_calibration: SET AUTO CALIBRATION
  > Sets a schedule for calibration at regular intervals.
- calibration_data: CALIBRATION DATA
  > Shows data from the last calibration and the due date and time of the next scheduled calibration.
- override_calibration: OVERRIDE CALIBRATION
  > Enters a new slope and/or zero value (reagent blank); disables automatic calibration for the selected option.
- output_calibration: OUTPUT CALIBRATION
  > Selects a 4–20 mA output and sets the output values to be sent.
- reset_default_cal: RESET DEFAULT CAL
  > Resets calibration data to default values and disables automatic calibration; recalibrate after use.

## Diag Menu

- diagnostics: DIAGNOSTICS
  > Shows errors and warnings for the instrument or installed modules; active warnings show until acknowledged or reset.
- prognosys: PROGNOSYS
  > Shows the variables that trigger the service indicator and the measurement health indicator on the display.
- current_status: CURRENT STATUS
  > Shows current instrument statuses: OPERATION, SAMPLE CHANNEL, STEP STATUS, STEP TIME, MINUTES LEFT, and COMPLETION.
- analyzer_help: ANALYZER HELP
  > Shows all possible errors, warnings and reminders with troubleshooting hints.
- perform_test: PERFORM TEST
  > Runs a diagnostic test for individual analyzer components.
- outputs: OUTPUTS
  > Shows the current status of the 4–20 mA and relay outputs with options to examine, hold and simulate.
- view_led: VIEW LED
  > Shines the LED in the colorimeter cell for improved viewing during troubleshooting; LED can stay on for 1 to 999 seconds.
- modbus_stats: MODBUS STATS
  > Shows the status of the Modbus ports (sensor, controller, network, service) and the number of good and bad transmissions.
- service: SERVICE
  > Shows service parts information and history: SERVICE PART, PART INFORMATION, UPCOMING SERVICE, SERVICE HISTORY.
- system_data: SYSTEM DATA
  > Shows system information: TEMPERATURE, POWER SOURCE FREQUENCY, POWER SOURCE VOLTAGE, 12 V VOLTAGE, 3.3 V VOLTAGE, 12 V CURRENT.
- i2c_data: I2C DATA
  > Shows the display information (I2C) and the version number.
- overfeed_reset: OVERFEED RESET
  > Resets the overfeed timer.

### PERFORM TEST

- reagent_delivery: REAGENT DELIVERY
  > Opens each reagent valve for a specified time (50 ms to 65 s) or a specified volume (20 to 9,999 µL).
- sample_delivery: SAMPLE DELIVERY
  > Opens each sample valve for a specified time (1 to 9999 seconds).
- cal_sol_delivery: CAL SOL. DELIVERY
  > Opens the calibration standard valve for a specified time (1 to 9999 seconds).
- mixer: MIXER
  > Starts the mixer clockwise or counterclockwise at a specified speed (10 to 500 rpm) for a specified time (1 to 9999 seconds).
- colorimeter_heater: COLORIMETER HEATER
  > Sets the colorimeter heater to a specified temperature (20 to 60 °C); measured temperature is shown.
- sample_heater: SAMPLE HEATER
  > Sets the sample heater to a specified temperature (20 to 60 °C); measured temperature is shown.
- colorimeter: COLORIMETER
  > Increases the colorimeter LED duty cycle in 5% increments from 0% until saturation; A2D counts are shown.
- status_led: STATUS LED
  > Operates each LED indicator on the front panel (off, red, green, yellow); runs continuously until stopped.
- a2d: A2D
  > Sets the colorimeter LED intensity to examine cell transmittance for the A2D output.
- air_pump: AIR PUMP
  > Changes and controls air pressure; SET SETPOINT (1 to 9.99 psi), LOW/HIGH DEADBAND (0 to 1 psi), SET LOW/HIGH VALUE (5–99.99 psi), START.
- fan: FAN
  > Adjusts the fan duty cycle.
- analyzer_type: ANALYZER TYPE
  > For use by technical support only.
- select_script: SELECT SCRIPT
  > Toggles between normal instrument script and test script.
- set_channels: SET CHANNELS
  > For use by technical support only.
